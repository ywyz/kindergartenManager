# ADR-0002：单用户 UI 与租户只读 API 是两个身份边界

- 状态：接受
- 日期：2026-08-22

## 背景

代码保留 JWT、密码、RBAC 和账号页面，但当前根路由直达 `/home`，中间件不鉴权，页面使用固定 tenant/user。与此同时 `/api/v1` 使用映射到 tenant 的 API Key。

## 决策

- 当前 UI 明确定义为固定身份单用户模式，不宣称登录/RBAC 生效。
- 外部 API 采用独立服务主体：API Key → tenant_id；可通过 HMAC 加固。
- API 的租户能力不推导出 UI 的多用户能力。
- 恢复认证必须作为完整功能切片设计和验收，不能只重新导入页面或打开中间件。

## 后果

- 本地 frozen 应只监听回环。
- 源码/Docker 对外监听时必须额外控制网络；在认证恢复前不应直接公网开放 UI。
- 旧账号管理手测只作为历史资料。
