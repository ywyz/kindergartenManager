## WP-F 回归与云端验收

| 范围 | 必须覆盖的结果 |
|---|---|
| 每日活动名称 | 拆分、缺失、手填、旧记录、新旧自定义提示词、保存重载、导出一致 |
| 权威班级 | 同名不同班、不同园、不同学期拒绝；未映射历史不被自动共享 |
| 共享 | 同班共用同一 plan；双教师同时创建不产生两份；同时保存一成一败 |
| 成员撤销 | 查询后撤销、AI 等待中撤销、导出等待中撤销均失败关闭 |
| 来源选择 | 零／一／多条；本人＋他人重复也提示；未选择不导入 |
| 来源快照 | 源修改、删除、不可见；提示重新导入，手改保留，旧周版本不变 |
| 人员 | 多位教师、默认更新、新建初始化；其他成员打开不覆盖共享姓名 |
| 日期 | 常规五天、前置周日六天、周六六天、跨月／跨年、周中单日及连续放假 |
| 学期 | 开学首周、结束末周、寒／暑假、整周放假继续计数、不同个人设置不改变班级周身份 |
| 日历异常 | 未支持年份明确失败；七列组合不静默丢弃日期；假期格不生成活动 |
| AI | 固定结构和数量、缺名称待手填、提示词版本、格式错误、超时、取消、上下文最小化 |
| 缩减 | 原文和候选差异，手工／导入内容须确认，拒绝不变，候选过期／并发失效 |
| 正文来源 | 周编辑与缩减不反写 DailyPlan，不保存 Provider 对话／长期候选 |
| 草稿导出 | 无审核可导出；未保存提示保存；绑定保存版本，成员／版本漂移不交付 |
| Word | 五／六列正常与长中文、多姓名、空格、书名号、目标数量、日期顺序、换行、无样例残留 |
| 单页 | A4、宋体小四、固定20 pt、实际一页、无裁切；无法收敛／缺字体／缺渲染器明确提示 |
| 隔离持久化 | 跨教师成功审计无正文；拒绝无 success；临时文件清理、无新增 ExportRecord |
| 兼容 | 旧五天周计划、旧不可变版本、月计划和每日计划现有功能不被误迁移或放宽权限 |
